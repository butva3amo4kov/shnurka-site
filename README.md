# Шнурка.ру

Статический сайт производителя шнурков и шнуров.

## Структура

- `index.html` — HTML-оболочка (меньше 39 КБ)
- `styles.css` — стили
- `app.js` — данные, страницы и интерактивность

## Локальный запуск

```bash
python3 -m http.server 8080
```

После запуска открыть `http://localhost:8080`.

## Важно

Формы пока работают в демонстрационном режиме: заявки сохраняются только в браузере и не отправляются на сервер.
